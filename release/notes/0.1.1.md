# Mimic SDK v0.1.1

This release improves page capability ownership and editor guidance across the SDKs.

- Repeated page capability lookups reuse the same attachment. Closing the capability detaches its extra CDP session while keeping the native browser Page open. Integration shutdown waits for pending detach operations, and closed Pages invalidate their capability handles.
- Native Playwright options and explicit Mimic launch, connection and context settings are available to editors and static type checkers. Python ships its type information; Ruby models expose named keyword constructors. Omitted fields and explicit JSON null retain their distinct meanings.
- C#, Java and PHP accept generated Mimic configuration types directly for context, media and resource-policy settings. The selected automation framework still provides its own browser, context, Page and locator objects.
- PHP adds `forPageCommands(page)` for page-scoped commands. Existing `forPage(page)` continues to resolve the Page's Context capabilities.

The default runtime is Mimic v0.2.4 for Windows and Linux amd64. Internal bootstrap preparation stays outside the public browser Context and target lists. Accepted page, Context and browser closure commands complete when their originating CDP connection disconnects; ordinary application work remains cancellable on disconnect.

Start with the [SDK quickstart](https://mimic.boo/sdk/) or the [installation guide](https://github.com/mimic-browser/sdk#readme). Current package availability is recorded in the main README.
